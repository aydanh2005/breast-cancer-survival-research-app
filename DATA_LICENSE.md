# Data License and Attribution

The file `data/processed/metabric_analysis_cohort.csv` is a derived dataset based on the publicly available METABRIC clinical data obtained through the cBioPortal DataHub.

Unless otherwise noted for a specific study, data distributed through the cBioPortal DataHub are made available under the Open Data Commons Open Database License (ODbL) 1.0. The derived dataset in this repository is therefore redistributed under the ODbL 1.0.

Public use of the dataset must provide appropriate attribution to cBioPortal and the original METABRIC publications. Shared or adapted versions of the dataset must remain open and must be offered under the same ODbL terms.
